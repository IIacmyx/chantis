# Последний букет

Сайт-подарок. Одна страница, открывается двойным кликом по `index.html`
в любом браузере, на телефоне и на компьютере. Интернет нужен только для
красивых шрифтов — без него сайт тоже работает, просто шрифт будет проще.

## Что нужно сделать (3 шага)

### 1. Положить фотографии
Скопируй фото в папку `photos` и назови их так:

```
photos/01.jpg
photos/02.jpg
photos/03.jpg
photos/04.jpg
photos/05.jpg
```

Порядок = порядок глав на сайте. Можно `.jpg`, `.png` или `.webp` —
главное, чтобы имя файла совпадало с тем, что написано в `js/data.js`.

Пока файла нет, на его месте видно аккуратную рамку с именем файла —
сайт не ломается.

### 2. Поправить тексты
Открой `js/data.js` любым текстовым редактором (даже «Блокнотом»).
Это единственный файл, который нужно трогать. Меняй только текст
между кавычками:

| Что | Где |
|---|---|
| Имена | `her`, `herName`, `herDative`, `him`, `monogram` |
| Дата свадьбы | `weddingDate`, `weddingDateLabel` |
| С какого дня вместе | `togetherSince` |
| Подписи у счётчика | `count` |

## Движение

- **Плавность прокрутки** — `js/main.js`, в блоке «ПЛАВНАЯ ПРОКРУТКА» число `0.11`.
  Меньше (0.07) — тяжелее и дольше катится, больше (0.2) — резче и ближе к обычной.
- **Скорость появления блоков** — `css/style.css`, блок `[data-reveal]`, значения `1s` / `1.15s`.
- **Размах параллакса** — `js/main.js`, `p * -14` в блоке «ПАРАЛЛАКС».
| Первый экран | `hero` |
| Главы истории | `story.chapters` |
| Галерея | `gallery.items` |
| Письмо | `letter.body` |
| Обещания | `vows.items` |
| Финал | `finale` |

Главу или обещание можно добавить — просто скопируй соседний блок
целиком, вместе с запятой.

### 3. Проверить
Открой `index.html` и пролистай до конца. Проверь на телефоне —
кинь себе всю папку в мессенджер или на флешку.

## Музыка (по желанию)
Положи файл `music.mp3` рядом с `index.html` — в шапке сама появится
кнопка звука. Браузеры не разрешают включать музыку без нажатия,
поэтому она стартует только по клику.

## Что внутри
```
index.html        разметка страницы
css/style.css     оформление
js/data.js        ← все тексты и настройки
js/main.js        логика (менять не нужно)
photos/           фотографии
```

## Если хочешь выложить в интернет
Залей всю папку целиком на любой бесплатный хостинг статических
сайтов (Netlify Drop, GitHub Pages, Vercel) — она полностью
самодостаточна, никакого сервера не требуется.
